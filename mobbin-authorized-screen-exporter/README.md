# Authorized Mobbin Screen Exporter

This is the end-to-end version for internal use. It saves screen image files, but it is designed to run against authorized sources only:

- staging Mobbin
- local dev Mobbin
- internal export endpoints
- backend-generated JSON manifests
- short-lived signed URLs generated by your own service

It does not scrape the production paywall bypass path.

## Endpoint Mode

```bash
export MOBBIN_EXPORT_TOKEN="..."

node authorized-mobbin-screen-exporter.mjs \
  --endpoint "https://staging.mobbin.com/internal/exports/screens?app=phantom-ios&includeRestricted=true" \
  --out phantom-screens \
  --allowHosts staging.mobbin.com,bytescale.mobbin.com \
  --concurrency 4
```

## Manifest Mode

```bash
node authorized-mobbin-screen-exporter.mjs \
  --manifest screens-export.json \
  --out phantom-screens \
  --allowHosts staging.mobbin.com,bytescale.mobbin.com
```

Accepted manifest shapes:

```json
{
  "screens": [
    {
      "id": "screen-id",
      "appName": "Phantom",
      "flowName": "Onboarding",
      "name": "Create wallet",
      "width": 1179,
      "height": 2556,
      "restricted": true,
      "imageUrl": "https://staging.mobbin.com/internal-assets/screen.webp"
    }
  ]
}
```

Also accepted:

```json
[{ "id": "screen-id", "src": "https://..." }]
```

## Outputs

The output folder contains:

- downloaded image files
- `export-report.json`
- `export-report.csv`

Each report row includes source host, saved path, byte size, content type, and SHA-256.

## Backend Contract Recommendation

Have the backend expose an internal endpoint that returns one record per screen:

```json
{
  "screens": [
    {
      "id": "uuid",
      "appId": "uuid",
      "appName": "Phantom",
      "flowId": "uuid",
      "flowName": "Setting a long position",
      "name": "Screen name",
      "width": 1179,
      "height": 2556,
      "restricted": true,
      "imageUrl": "https://signed-or-internal-url"
    }
  ]
}
```

That lets your team validate the full download path without relying on an unauthorized production route.
